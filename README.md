# Spotly

Coming soon page for **Spotly** — know where you'll park before you arrive.

## Stack

- Next.js (App Router)
- Tailwind CSS v4
- Custom i18n (`en` / `ar`) with RTL support

## Develop

```bash
npm run dev
```

- English: [http://localhost:3000/en](http://localhost:3000/en)
- Arabic: [http://localhost:3000/ar](http://localhost:3000/ar)
